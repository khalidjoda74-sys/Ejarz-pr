# عقود برو — Flutter UI

واجهة Flutter عربية كاملة لتطبيق **عقود برو**، مبنية لتطابق المرجع البصري المرفق قدر الإمكان، مع تصميم RTL واستجابة لمقاسات الجوال المختلفة.

## الموجود في المشروع

- شاشة البداية والتعريف بالتطبيق.
- تسجيل الدخول، إنشاء حساب، والتحقق برمز OTP تجريبي.
- شاشة اختيار الاشتراك والدفع التجريبي.
- الرئيسية، عقودي، إنشاء عقد، المحفظة، وحسابي.
- قائمة جانبية عربية من اليمين.
- معالج إنشاء عقد كامل:
  1. نوع العقد وصفة المستخدم.
  2. بيانات العقار والوحدة.
  3. بيانات المؤجر والمستأجر والممثل القانوني.
  4. المدة والبيانات المالية والخدمات وجدول الدفعات والشروط.
  5. المرفقات.
  6. المراجعة والدفع وإرسال الطلب.
- قائمة العقود، الفلاتر، البحث، وتتبع حالة العقد.
- الإشعارات، الدعم الفني، الإعدادات، السياسات، والاشتراك.
- بيانات تجريبية وخدمات وهمية جاهزة للاستبدال بواجهات API الحقيقية.

## التشغيل

```bash
flutter pub get
flutter run
```

رمز التحقق التجريبي: `1234`

## نقاط الربط المستقبلية

أماكن الربط موضحة داخل `lib/core/app_controller.dart` و`lib/screens/create_contract.dart`:

- تسجيل الدخول والهوية.
- رفع الملفات الحقيقي.
- بوابة الدفع.
- API منصة إيجار.
- حفظ البيانات في قاعدة بيانات.

المشروع لا يحتوي مفاتيح سرية أو بيانات إنتاجية.
